# Sample resumes

Fake resumes for testing the text extractors. Every name, email and phone number
is made up. Never add a real person's resume here.

| File | Layout | Skills checked by `tests/test_sample_resumes.py` |
|---|---|---|
| `plain_resume.pdf` | One column | Python, SQL, Git |
| `plain_resume.docx` | One column | Python, SQL, Git |
| `two_column_resume.pdf` | Two columns | Java, Docker, Linux |
| `skills_table_resume.pdf` | Skills in a table | Python, Docker, AWS |
| `skills_table_resume.docx` | Skills in a table | Python, Docker, AWS |
